# ADR-002. Паттерны доступа к данным: Repository + Unit of Work

## Статус
Принято

## Контекст
Требуется атомарный импорт до 1 млн записей с откатом при ошибках
валидации, а также тестируемость бизнес-логики без реальной БД.

## Решение
Использовать Repository (абстракция над SQLAlchemy) и Unit of Work
(управление транзакцией и набором репозиториев в рамках сценария).

## Альтернативы
1. Прямые запросы к ORM в сервисах — быстро, но связно и сложно тестировать.
2. Active Record — снижает изоляцию Domain от инфраструктуры.
3. CQRS с отдельными read/write моделями — избыточно для MVP.

## Последствия
+ Тестируемость (mock-репозитории), атомарность импорта.
− Дополнительный слой абстракции, чуть больше кода.
