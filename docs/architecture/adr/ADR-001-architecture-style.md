# ADR-001. Выбор архитектурного стиля

## Статус
Принято

## Контекст
Проект «Business Metrics Analyzer» разрабатывается командой из 3–4 человек.
Требуется быстрый MVP с возможностью последующего масштабирования.
Ключевые NFR: отклик дашборда ≤ 3 с, импорт до 1 млн записей, RBAC, Docker.

## Решение
Выбран слоистый монолит с элементами Clean Architecture.

## Альтернативы
1. Микросервисы — избыточны для MVP, высокая сложность инфраструктуры.
2. Чистый монолит без слоёв — быстрее старт, но высокая связность.
3. Serverless — плохо подходит для длительного импорта и предсказуемой нагрузки на БД.

## Последствия
+ Быстрый старт, единый деплой, изоляция бизнес-логики.
− Ограниченное независимое масштабирование компонентов.
