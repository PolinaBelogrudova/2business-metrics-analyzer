## Описание бизнес-процессов

### Процесс AS-IS (Как есть сейчас)
**Цель:** Формирование отчётов по продажам вручную.  
**Участники:** Менеджер по продажам, Аналитик, Коммерческий директор.  

**Описание потока работ:**
1. Менеджер по продажам выгружает сырые данные из CRM-системы в формате CSV/Excel.
2. Менеджер пересылает файл аналитику по почте или в мессенджере.
3. Аналитик вручную сводит данные в Excel, очищает их от ошибок и рассчитывает KPI (выручка, средний чек, конверсия).
4. Процесс занимает 2–3 дня из-за ручных операций и возможных ошибок в данных.
5. Аналитик отправляет готовый статичный отчёт коммерческому директору.

**Проблемы процесса:** Высокая трудоёмкость, задержка данных на 2–3 дня, риск человеческих ошибок, отсутствие оперативной аналитики.

---

### Процесс TO-BE (Как будет после внедрения)
**Цель:** Автоматизированный расчёт и визуализация KPI в реальном времени.  
**Участники:** Система Business Metrics Analyzer, Коммерческий директор, Аналитик.  

**Описание потока работ:**
1. Система «Business Metrics Analyzer» автоматически забирает данные из CRM по расписанию (или через API).
2. Система автоматически валидирует данные и рассчитывает KPI в реальном времени.
3. Коммерческий директор открывает веб-приложение и видит актуальный дашборд без задержек.
4. При необходимости аналитик или директор формирует детализированный отчёт в один клик и экспортирует его в Excel.

**Преимущества процесса:** Сокращение времени формирования отчёта с 2–3 дней до нескольких секунд, исключение ручных ошибок, оперативное принятие управленческих решений.

## Описание бизнес-процесса «как есть» (AS-IS)

### Участники процесса
| Роль | Ответственность |
|---|---|
| Менеджер по продажам | Вносит данные о продажах в CRM/1С |
| Аналитик | Собирает данные из разных источников, формирует отчёты вручную в Excel |
| Коммерческий директор | Получает отчёты, принимает решения на их основе |

### Текущий процесс
1. Менеджеры в течение дня/недели вносят данные о продажах в CRM и 1С.
2. В конце отчётного периода аналитик вручную выгружает данные из CRM и 1С.
3. Аналитик сводит данные в Excel, рассчитывает KPI (выручка, средний чек, конверсия, рентабельность) с помощью формул.
4. Аналитик формирует итоговый отчёт и отправляет его коммерческому директору по почте.
5. Директор изучает отчёт и принимает управленческие решения.

### Проблемы текущего процесса
| ID | Проблема | Последствие |
|---|---|---|
| P-01 | Ручной сбор данных из нескольких источников | Высокие трудозатраты аналитика |
| P-02 | Формирование отчёта занимает 2–3 дня | Решения принимаются с задержкой, данные устаревают |
| P-03 | Человеческий фактор при расчётах | Ошибки в KPI, недостоверная аналитика |
| P-04 | Нет единого источника актуальных показателей | Разные версии отчётов у разных сотрудников |
| P-05 | Отсутствует визуализация в реальном времени | Невозможно оперативно реагировать на изменения |

## Описание бизнес-процесса «как будет» (TO-BE)

### Участники процесса
| Роль | Ответственность |
|---|---|
| Менеджер по продажам | Вносит данные о продажах в CRM/1С (как и раньше) |
| Система Business Metrics Analyzer | Автоматически собирает данные, рассчитывает KPI, строит дашборд и отчёты |
| Коммерческий директор | Просматривает актуальные показатели в реальном времени, принимает решения |
| Аналитик | Настраивает отчёты, проводит углублённый анализ при необходимости |

### Новый процесс
1. Менеджеры вносят данные о продажах в CRM и 1С.
2. Система **Business Metrics Analyzer** автоматически загружает данные из CRM/1С по расписанию или в реальном времени.
3. Система рассчитывает ключевые KPI (выручка, средний чек, конверсия, рентабельность) и отображает их на дашборде.
4. Коммерческий директор в любой момент открывает веб-приложение и видит актуальные показатели.
5. При необходимости пользователь формирует отчёт за выбранный период и экспортирует его в Excel одним кликом.

### Ожидаемые улучшения
| ID | Улучшение | Эффект |
|---|---|---|
| I-01 | Автоматическая загрузка данных из CRM/1С | Исключён ручной сбор, экономия времени аналитика |
| I-02 | Расчёт KPI выполняется системой | Отсутствие ошибок, связанных с человеческим фактором |
| I-03 | Дашборд с показателями в реальном времени | Время формирования отчёта сокращается с 2–3 дней до нескольких минут |
| I-04 | Единый источник данных для всех пользователей | Консистентность показателей, одна версия правды |
| I-05 | Экспорт отчётов в Excel по запросу | Удобство для дальнейшего использования и передачи |
| I-06 | Разграничение прав доступа | Безопасность коммерческих данных |

### Метрики эффективности перехода AS-IS → TO-BE
| Метрика | AS-IS | TO-BE |
|---|---|---|
| Время формирования отчёта | 2–3 дня | Несколько минут |
| Актуальность данных | На конец периода | В реальном времени |
| Трудозатраты аналитика на отчёт | Высокие | Минимальные |
| Вероятность ошибок в расчётах | Средняя | Низкая |
