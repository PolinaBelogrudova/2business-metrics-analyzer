# Бизнес-требования — Business Metrics Analyzer

## Бизнес-требования
| ID | Требование | Источник | Приоритет |
|---|---|---|---|
| BR-01 | Автоматизировать расчёт ключевых KPI продаж | Коммерческий директор | Must have |
| BR-02 | Сократить время формирования отчётов с 2–3 дней до нескольких минут | Коммерческий директор | Must have |
| BR-03 | Обеспечить руководству доступ к показателям в реальном времени | Коммерческий директор | Must have |

## Функциональные требования
| ID | Требование | Связанная User Story | Приоритет |
|---|---|---|---|
| FR-01 | Система должна отображать дашборд с KPI (выручка, средний чек, конверсия, рентабельность) | US-01 | Must have |
| FR-02 | Система должна позволять формировать отчёты по продажам за выбранный период | US-02 | Must have |
| FR-03 | Система должна загружать данные о продажах из внешних источников (CRM/1С) | US-03 | Must have |
| FR-04 | Система должна экспортировать сформированные отчёты в формат Excel | US-04 | Should have |
| FR-05 | Система должна управлять пользователями и разграничивать права доступа | US-05 | Should have |

## Нефункциональные требования
| ID | Требование | Категория | Метрика |
|---|---|---|---|
| NFR-01 | Время загрузки и отрисовки дашборда | Производительность | < 3 секунд |
| NFR-02 | Доступность веб-приложения для пользователей | Надёжность | 99.5% uptime |
| NFR-03 | Защита коммерческих данных при передаче и хранении | Безопасность | HTTPS, ролевая модель доступа |

## Ограничения
| ID | Ограничение | Описание |
|---|---|---|
| CN-01 | Бюджет | Ограниченный бюджет на разработку начальной версии (MVP) |
| CN-02 | Сроки | Запуск первой рабочей версии через 2 месяца |
| CN-03 | Интеграция | Обязательная совместимость с существующей CRM-системой компании |
